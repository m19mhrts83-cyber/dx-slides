# dx-slides

DX互助会 第1回勉強会「Cursor × Markdown活用入門 〜不動産業務を効率化する第一歩〜」のプレゼンテーション資料です。

## 概要

- **対象イベント**: DX互助会 第1回勉強会（2026年1月31日）
- **内容**: Markdown の基本、Cursor での活用例、不動産業務への応用、HTML 資料作成の可能性など（全17スライド）
- **形式**: 単一の HTML ファイル（`index.html`）。ビルドやサーバーは不要です

## 閲覧方法

1. リポジトリをクローンまたはダウンロードする
2. `index.html` をブラウザで開く（ダブルクリック、またはファイルをブラウザにドラッグ＆ドロップ）

```bash
# 例（macOS）
open index.html

# 例（Windows）
start index.html

# 例（Linux）
xdg-open index.html
```

## 操作

| 操作 | 動作 |
|------|------|
| `→`（右矢印）または `Space` | 次のスライドへ |
| `←`（左矢印） | 前のスライドへ |
| 画面右下の「次へ ▶」「◀ 前へ」ボタン | スライドの前後移動 |
| 画面左下のページ番号 | 現在位置の確認（例: `1 / 17`） |

※ 最初・最後のスライドでは、それ以上進めない／戻れない方向の操作は無効になります。

## ファイル構成

```
dx-slides/
├── README.md                          # このファイル
├── index.html                         # プレゼンスライド本体
└── プロンプト_入居者募集案内自動化.md   # 勉強会配布用の参考資料
```

### `index.html`

勉強会で使用するスライド本体です。CSS と JavaScript が同梱されており、追加の依存関係はありません。

### `プロンプト_入居者募集案内自動化.md`

Cursor 上で「入居者募集案内のメール送信を自動化する」相談から実装まで進めた際の会話ログ（プロンプト例）です。勉強会で紹介したメール自動化の具体例として、依頼の出し方や改善の進め方の参考にしてください。

## 収録資料の使い分け

- `index.html`: 勉強会当日に閲覧するHTMLスライド
- `プロンプト_入居者募集案内自動化.md`: 実務自動化の相談・実装例を確認するための参考資料
